# The Joke About the Demo

A one-line joke about working beside an AI coding agent, written by a small
Node program (`main.ts`, standard library only, no network) that validates the
joke's length and writes it to `/output/entry.txt`. Built for a $50 bounty on
make.fun, where you can earn money building software with AI.
